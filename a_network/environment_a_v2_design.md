# A v2 环境构建版设计：解析背板 + 神经残余 + 硬约束 + 作用量奖励

**版本**：2026-09-29（初稿）
**地位**：本文是架构文档 §2.2「网络 A」的 **v2 细化**，是 Phase 1 收尾后进入
「环境构建 → RL」阶段的**下一步入口**。Phase 1 的 A（GINE 纯回归器）保留为
探针与对照，不再直接升任环境。

---

## 0. 动机：为什么环境必须重做

架构文档 §1.4 定义 A = 「通用物理知识学习器（**环境 + 裁判**）」＝
「**拉氏量代理 + DPI 判据**」。Phase 1 的实现偏离了这一定义：七项损失中没有
拉格朗日量项，DPI「约束头」是失效影子（第 26 条硬证据）。而 Phase 1 的整场
战役给出了**必须重做的经验证据**：

| 证据（HANDOVER 条目） | 结论 | 对环境构建的含义 |
|---|---|---|
| 第 26–29 条：族级 OOD R² 为负到弱正；约束干净效应 = 方差稳定 + 链族提升 | 纯学习回归器在新结构处不可信 | 环境在 OOD 处的可信性**不能来自外推** |
| 第 30–31 条：landau 训练内 R²=0.103，四步诊断 + 探针裁决——根因大头是管线混杂（共享列标准化极端尺度/掩码扰动/多任务稀释），编码非单射只是小头（0.12 R²） | 纯学习回归器连训练内都不可靠；R2b 开关保留默认关 | 解析量必须直接计算，**不过学习**；残余学习必须配门控 |
| 第 29 条：约束 B/编辑头泄漏抬高收益 | 评估协议必须防泄漏 | V1–V4 验证沿用固定 holdout + 泄漏防护协议 |
| 第 30 条 Q3c：不确定度头能识别 landau（var 4×） | 拒绝门控可行 | R5 门控是残余学习的兜底 |

**RL 智能体的探测点永远是训练集外的新结构**（加节点/改参数/改容量），因此：
*环境必须「按构造可信」——可信性由解析项保证，学习只负责理论没有闭式的残余。*

---

## 1. 设计原则

1. **OOD 可信性来自解析项，不来自外推**。所有理论有闭式/已验证数值解的量，
   一律解析计算，不走网络。
2. **学习范围最小化**。网络只学理论没有闭式的部分（IB 曲线、模板外组合、
   编辑效应的残余修正）。
3. **裁判需要硬保证**。DPI 单调性、容量上限是硬约束（构造进网络/截断），
   违反 = 结构非法，直接拒绝并给理由（供 RL 奖励塑形），不是软惩罚。
4. **作用量是奖励函数本体**。信息拉格朗日量在这里成为结构：RL 的结构编辑
   轨迹 q(t) 提供动能项所需的 q̇，作用量 ∫L dt 即奖励。
5. **向后兼容与可复现**。Phase 1 的纯回归器与全部基线保持逐位可复现；A v2
   是**新增组件**，不破坏既有实验。

## 2. 组件设计

### 2.1 解析背板（Analytic Backbone）

**输入**：信息结构图 G=(V,E,Θ)（B 编码器的输出，与 Phase 1 同）。

**逐节点**：按 `distribution_family + params` 解析计算 Fisher 摘要
（trace/det/全矩阵）：

- 17 族闭式/已验证数值解全部复用 `core/fisher.py`；
- **landau 直接用数值求积**（固定网格梯形积分，对 a/b/kT 可微——固定网格下
  被积函数解析，autograd 直通）；
- 输出节点 Fisher 的同时输出**可微性标记**（M1 标注 `closed_form`/`torch_ready`，
  torch autograd 移植在 M2：闭式族直通；landau 数值求积用固定网格 autograd；
  MC=不可微，仅前向）。

**逐边**：按通道模板解析计算 MI（`core/channels.py` 22 模板）。模板外的
新组合 → 交给神经残余 + 置 `covered=False`（门控依据）。

**链级**：DPI 单调性检查（`I(X;T1) ≥ I(X;T2) ≥ …` 沿链），**硬判据**：
违反即 `legal=False`，附违反链位。

**输出**：`(F_analytic, MI_analytic, dpi_ok, covered_flags, action 分量)`。

> 注：DB2 本身就是这条解析管线生成的，因此 V1 验证（背板 vs DB2）应逐位一致。

### 2.2 神经残余（Neural Residual）

只学**理论没有闭式**的量：

| 残余目标 | 慢路径真值 | 备注 |
|---|---|---|
| IB 曲线 I(T;Y)@β | Blahut-Arimoto（`core/ib.py`） | 训练期慢算建真值；推理期网络替代；沿用 `_IB_CACHE` 类缓存教训（第 6.2 条） |
| 模板外组合的 MI | 数值积分/采样 | `covered=False` 时启用 |
| 编辑效应残余 Δ 修正 | 慢路径重编码（`edit_pipeline.py` 现有） | 解析背板能算的编辑不建学习对 |

**输入**：图张量（复用 `graph_dataset.py`；R2b 开关已就位、默认关，第 31 条）+ 解析背板
输出作为特征。**输出**：残余预测 + 不确定度（复用六头中的 uncertainty 头）。

**关键纪律**：残余真值 = 慢路径 − 解析背板（解析可算处真值为 0，网络学会
「闭嘴」）；残余失败必须被 R5 门控捕获（见 2.5）。

### 2.3 硬约束（Hard Constraints）

- **DPI 单调性**：沿链的 log Fisher 用**单调参数化**构造（如相邻差取
  softplus 累积），网络输出天然满足单调，不需要损失项；
- **容量/功耗上限**：硬性截断；
- **非法结构拒绝**：`legal=False` 时环境返回拒绝 + 原因，RL 奖励给大惩罚
  （奖励塑形，不静默）。

### 2.4 作用量奖励（Action Reward）

对 RL 的结构编辑轨迹 q(t)（节点/参数/容量的离散编辑序列）：

```
A[q] = Σ_edges ½ g_ij Δq_i Δq_j  −  [ I(X;T) − β·I(T;Y) ]
        动能项（Fisher 度量，解析背板提供 g_ij）
        势能项（IB 泛函：神经残余 / 缓存 BA 查表）
```

- β 来自 DB3 需求映射（q 规格），接需求通路；
- 实现复用 `core/action.py:info_action`——**从零调用升级为核心调用**（第 26 条
  记录的缺口在此闭合）；
- 离散轨迹下 Δq 用相邻状态差，动能项即「结构改变的 Fisher 代价」。

### 2.5 拒绝门控（双条件，第 30/32 条标定后修订）

第 30 条 Q3c + 第 32 条 R5 标定：`pred_var` 在节点级有真实排序信息（ρ=0.46），
但**全局阈值选错对象**（拒绝 laplace 80% 却放行 negbin 的「自信灾难」——var
反映训练残差结构，对 OOD 失明；族间 var 水平差一个量级）。因此门控为**双条件**：

1. `covered=False`（模板外 / 残余路径）→ 直接拒绝；
2. `covered=True` 但不确定度超过**分族标定**阈值 → 拒绝。

解析背板覆盖的已知族（含 landau——Fisher 由背板直接解析计算）**不经过 var
门控**。RL 只能消费高置信分量（拒绝分量置 0 并惩罚）。分族阈值在 M3 用
训练/验证数据标定（**不得用评估数据标定，防循环论证**）。目标是「正确地说
不知道」，而非「给出一个自信的错误答案」。

## 3. 数据流与接口

```
RL 智能体 ──结构编辑──▶ 信息结构图 G ──┬─ 解析背板 ──▶ F, MI, dpi_ok, g_ij（可信）
                                        └─ 神经残余 ──▶ IB 曲线、模板外 MI、Δ 修正（带不确定度）
        ◀── 奖励 = 作用量 A[q]（动能 g_ij + 势能 IB；β 来自 DB3）+ 合法性惩罚
        ◀── 环境状态：{指纹摘要, 合法性, 拒绝标记, 不确定度}
```

与 B/C 的边界不变：A 只吃 B 的输出；C 只消费 RL 产出的最优结构。

## 6. 风险与边界

1. **模板外结构的解析回退**：`covered=False` 路径依赖神经残余——必须配门控，
   否则 RL 会钻到不可信区域（这就是 V2/V3 的重点）。
2. **landau 数值积分的 autograd 成本**：固定网格 2000 点/节点，每步梯度可接受
   （比 300 epoch 训练便宜）；若成瓶颈，降网格 + 缓存。
3. **IB 慢路径缓存**：复用 `FingerprintComputer._IB_CACHE` 的
   `(channel, range, bins)` 键设计（第 6.2 条教训），训练期离线建表。
4. **向后兼容**：A v2 是新增模块；`train_gine.py` 与全部归档指标不受影响。
